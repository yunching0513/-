Google Cloud Text-to-Speech

Without a key the app speaks with your browser’s built-in German voice, which is usually flat and robotic. A Google key gives you the Chirp3 HD and Neural2 voices, which is what makes shadowing worth doing. Every clip is cached in this browser, so repeating a sentence a hundred times costs one synthesis.

How to get a key, and how to keep it safe
  1. Open Google Cloud Console and create (or pick) a project.
  2. Enable Cloud Text-to-Speech API under APIs & Services → Library.
  3. Credentials → Create credentials → API key.
  4. Open the key and restrict it: API restrictions → Cloud Text-to-Speech API only; Application restrictions → HTTP referrers, listing only the address you run this app from.
  5. Paste it above. It is stored in this browser’s localStorage and sent only to texttospeech.googleapis.com.

The free tier covers 1 million standard characters and 100k WaveNet/Neural2 characters a month. A1 sentences run 30–60 characters, and the cache means each one is billed once.

Drilling

The silence between the prompt and the answer. Fill it out loud — recall only strengthens memory when you actually attempt it.

About

Nochmal drills in two nested loops. Within a session a missed sentence returns after 3, then 8, then 16 other cards: Pimsleur’s graduated interval recall. Across days each sentence carries an SM-2 ease factor, so the gap grows 1 → 4 → 10 → 25 days as long as you keep getting it right. Nothing is uploaded; progress and audio stay in this browser.
