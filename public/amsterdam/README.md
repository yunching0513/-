# 阿姆斯特丹開放地理資料探索器

串接阿姆斯特丹市政府[Maps Data開放地理資料](https://maps.amsterdam.nl/open_geodata/)的互動地圖，
內建15分鐘城市步行可及性分析與行政區設施密度比較。

不需要建置、不需要後端、不需要API金鑰：一個HTML加上四個JavaScript檔案，
資料在瀏覽器裡直接向市政府端點取得。

## 怎麼開起來

資料端點回應標頭帶有`access-control-allow-origin: *`，瀏覽器可直接跨域取用。
但頁面本身建議透過HTTP伺服器開啟（用`file://`直接開檔時，部分瀏覽器會把
跨域請求的來源視為`null`而擋下）：

```bash
# 方法一：任何靜態伺服器
cd public/amsterdam && python3 -m http.server 8000
# 開啟 http://localhost:8000

# 方法二：跟著本專案的Next.js一起跑，檔案在public/底下會自動被服務
npm run dev
# 開啟 http://localhost:3000/amsterdam/
```

部署到Vercel之後，網址是`https://<你的網域>/amsterdam/`。

## 三個分頁

### 圖層

17個圖層加2種行政界線，按需載入。顏色只編碼三個主題群，個別圖層靠符號區分
（原因見下方「配色怎麼決定的」）。載入後的圖層會出現篩選器，可依屬性值挑選子集，
篩選同時作用於地圖與可及性分析。

荷蘭文的屬性值都附上中文對照，popup裡以「中文（原文）」呈現，方便回溯原始資料。

### 15分鐘分析

在地圖上選一個位置，計算步行圈內可及的生活機能。機能領域的分法參考
Moreno et al. (2021)對15分鐘城市的六大社會功能，依阿姆斯特丹實際可得的開放資料
調整為供給、照顧、學習、享受、移動、綠意六類。

**方法上的限制必須講清楚**：畫出來的是直線緩衝區，不是路網等時圈。
實際步行得沿街廓繞行，所以半徑先除以一個繞行係數（circuity ratio）再上圖：

```
有效半徑 ＝ 分鐘數 × 步行速度 ÷ 繞行係數
```

預設步速80公尺／分鐘（4.8公里／小時），繞行係數1.3。都市路網的實測繞行係數多落在
1.2到1.4之間，兩個參數都能在介面上調整；係數設為1.00就退回單純的直線距離。
要得到真正的路網等時圈，需要另接OSRM或Valhalla這類路徑服務，本頁不做這件事。

距離判定上，點圖層用haversine大圓距離；面圖層則同時檢查「圓心是否落在面內」與
「面的頂點是否進入圓」，因此大面積公園即使重心很遠也會被算進來。

分析結果可下載成CSV，檔尾附上中心點座標、步速、繞行係數與各圈半徑。

### 行政區比較

以行政區（Stadsdeel，9區）或鄰里（Buurt，518區）為單位，統計設施數與每平方公里密度。
歸屬一律用空間判定，不採信圖層自帶的行政區欄位，避免不同圖層的寫法不一致而無法比較。

界線用的是排除水域的版本，所以落在水面或市界之外的圖徵歸不進任何一區。
這個差額會顯示在面板上也寫進CSV，例如845筆公共運動場地裡有11筆歸不進去。

## 配色怎麼決定的

地圖是「任兩個標記都可能相鄰」的情境，色彩檢查必須用all-pairs而非相鄰對。
實測後，能在淺色與深色兩種模式都通過色覺辨識障礙分離度與一般視覺分離度的，
是三個色相：

| 主題群 | 淺色 | 深色 |
|---|---|---|
| 移動與公共服務 | `#2a78d6` | `#3987e5` |
| 生活、文化與遊憩 | `#eb6834` | `#d95926` |
| 綠地、生態與氣候 | `#1baf7a` | `#199e70` |

所以顏色只編碼主題群，17個圖層的識別交給符號：同一個符號會出現在圖例、地圖標記與
popup標題，讓識別不會只依賴顏色。行政界線用中性灰，不佔用主題色。
深色模式的色階是為深色底重新取階的，不是把淺色模式反轉。

## 檔案結構

```
public/amsterdam/
├── index.html          頁面骨架
├── styles.css          色彩token與版面，淺色／深色各自定義
└── js/
    ├── datasets.js     圖層目錄：端點參數、主題群、欄位中文對照、機能領域對應
    ├── symbols.js      圖層符號（24×24線稿）
    ├── geo.js          幾何運算：haversine、代表點、點在多邊形內、外接框
    ├── api.js          資料取用與快取（記憶體＋sessionStorage）
    ├── analysis.js     15分鐘可及性與行政區統計
    ├── ui.js           介面渲染，不碰地圖
    └── app.js          地圖、事件與狀態
```

## 要加新圖層的話

在[Maps Data](https://maps.amsterdam.nl/open_geodata/)點選想要的資料集，
記下它的`KAARTLAAG`與`THEMA`（下載連結的查詢參數裡看得到），然後在
`js/datasets.js`的`LAYERS`加一筆：

```js
{
  id: 'zebrapaden', kaartlaag: 'ZEBRAPADEN', thema: 'zebrapaden',
  name: '行人穿越道', nl: 'Zebrapaden',
  theme: 'mobility',            // mobility | living | green
  render: 'icon',               // icon（<400筆）| dot（大量點）| line | polygon
  icon: 'route', count: 1754, bytes: 300000,
  fn: 'moving',                 // 對應的機能領域，不參與分析就省略
  title: (p) => p.Naam,
  fields: [['Soort', '型式']],  // popup 要顯示的欄位與中文標籤
  facet: { key: 'Soort', label: '型式' },
}
```

`render`選`icon`的圖層會用HTML標記（可放符號），`dot`則走canvas繪製，
數千個點也不卡。超過24種值的欄位不適合當篩選器，介面會自動略過。
